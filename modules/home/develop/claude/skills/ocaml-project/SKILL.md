# OCaml Project Structure

Follow the `ocaml` rule stack for style and `rules/engineering-discipline.md`
for process. This file covers layout and build configuration only. When the
stack is not copied into this project, `claude-stack add ocaml` copies it.

## Layout

```
myproj/
├── dune-project
├── myproj.opam          # generated by dune, committed
├── .ocamlformat
├── .gitignore
├── lib/
│   ├── dune
│   ├── store.ml
│   └── store.mli
├── bin/
│   ├── dune
│   └── main.ml
└── test/
    ├── dune
    └── test_store.ml
```

One library per directory. Logic lives in `lib/`. `bin/` parses arguments and
exits, nothing more, because code in `bin/` cannot be linked into a test.

For several packages in one repository, keep one `dune-project` at the root and
one `(package)` stanza per package, with each package in its own subdirectory.

## dune-project

```
(lang dune 3.16)
(name myproj)
(generate_opam_files true)

(source (github me/myproj))
(license ISC)
(authors "Me")
(maintainers "me@example.com")

(package
 (name myproj)
 (synopsis "One line, no trailing period")
 (description "A longer paragraph for the opam repository.")
 (depends
  (ocaml (>= 5.1))
  (eio_main (>= 1.0))
  (logs (>= 0.7.0))
  (alcotest :with-test)
  (qcheck-alcotest :with-test)
  (odoc :with-doc)))
```

`generate_opam_files true` makes `dune-project` the single source of truth.
Commit the generated `.opam` so opam consumers do not need dune to read the
metadata. Never hand-edit the generated file.

## Stanzas

### Library

```
(library
 (name store)
 (public_name myproj)
 (libraries eio logs)
 (flags (:standard -w +a-4-9-40-41-42-44-45-70 -warn-error +a)))
```

`(name store)` is the internal name and the wrapping module. Modules `store.ml`
and `store/foo.ml` are reachable as `Store` and `Store.Foo`. `(public_name ...)`
is what other packages depend on.

`-warn-error +a` makes warnings errors. Keep it in the dev profile. Release
builds relax it so a consumer's newer compiler cannot fail your build.

### Executable

```
(executable
 (name main)
 (public_name myproj)
 (libraries store eio_main cmdliner))
```

### Test

```
(test
 (name test_store)
 (libraries store alcotest qcheck-alcotest eio_main))
```

`(test ...)` attaches to the `runtest` alias automatically. For expect tests add
`(preprocess (pps ppx_expect))` and accept new output with `dune promote`.

### Instrumentation for coverage

```
(library
 (name store)
 (public_name myproj)
 (libraries eio)
 (instrumentation (backend bisect_ppx)))
```

Coverage stays off until asked for:
`dune runtest --instrument-with bisect_ppx && bisect-ppx-report summary`.

## .ocamlformat

```
version = 0.27.0
profile = default
margin = 90
```

Pin `version`. An unpinned formatter reformats the repository whenever a
machine has a different ocamlformat, which buries real diffs.

## Module workflow

Write the `.mli` first. It is the design step and it is free to change before
the `.ml` exists.

```ocaml
(* lib/store.mli *)

(** Persistent key-value store backed by a single file. *)

type t
(** An open store handle. *)

type error =
  | Corrupt of { offset : int }
  | Io of string

val pp_error : Format.formatter -> error -> unit

val open_ :
  sw:Eio.Switch.t -> Eio.Fs.dir_ty Eio.Path.t -> (t, error) result
(** [open_ ~sw path] opens the store at [path], creating it when absent.
    The handle closes when [sw] finishes. *)

val get : t -> string -> string option
val set : t -> key:string -> data:string -> (unit, error) result
```

Generate a starting `.mli` from an existing `.ml` with
`dune build @check && ocaml-print-intf _build/default/lib/.store.objs/byte/store.cmi`,
then cut it down to the real interface. Never ship the generated file as is.

## Adding a dependency

1. Add it to `depends` in `dune-project` with a lower bound.
2. Add it to `libraries` in the stanza that uses it.
3. `opam install --deps-only --with-test --with-doc .`
4. `dune build @all`

A dependency without a version bound is a future breakage with no diagnosis.
Per `rules/engineering-discipline.md`, ask before adding one.

## Pinning and locking

```bash
opam pin add mylib.dev git+https://github.com/me/mylib.git#main
opam pin remove mylib            # before release, always

opam lock                        # writes myproj.opam.locked
opam switch create . --locked    # reproduce elsewhere
```

## CI

Gate on everything a reviewer would otherwise check by hand:

```yaml
- run: opam install --deps-only --with-test --with-doc .
- run: opam exec -- dune build @fmt          # format check
- run: opam exec -- dune build @all          # compile, warnings as errors
- run: opam exec -- dune runtest
- run: opam exec -- dune build @doc
```

`dune build` alone builds the default alias and skips tests and doc targets.
`@all` is the one that matters.
